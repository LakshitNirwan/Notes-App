# Notes-App

A simple notes application that allows users to create, view, and delete notes in the browser.

## Features
- Add and delete notes
- Dynamic rendering of notes
- Simple and clean UI

## Tech Stack
- HTML
- CSS
- JavaScript

## What I learned
- Handling user input
- Managing dynamic data in JavaScript
- Updating the UI based on state
- Basic CRUD operations (Create, Read, Delete)
